# Code of conduct

This applies to issues, pull requests and all other project spaces.

- Be civil. Criticize the code, not the person.
- No harassment, no insults, no discriminatory language.
- No sexual language or images.
- Do not publish private information about another person.
- Stay on the subject of the project.

The maintainer can edit or remove a comment, close a thread, or block an
account that breaks these rules.

To report a problem in private, use
[a private report](https://github.com/nbhansen/Talrum/security/advisories/new)
and start the title with "Conduct".
