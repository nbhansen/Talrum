# Security

Talrum holds data about children. Report a security defect in private.

## How to report

Use [Report a vulnerability](https://github.com/nbhansen/Talrum/security/advisories/new)
on GitHub. Only the maintainer can read the report. Do not open a public
issue and do not put details in a pull request.

Include the steps that show the defect and what data or account it affects.

## What to expect

The project has one maintainer. Expect a first answer in about one week.

## Scope

The `main` branch and the deployed app. A self-hosted copy with changed
configuration is out of scope, unless the defect is also in `main`.
